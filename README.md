# S.T.E.W.A.R.D.Purser

Ядро на Python для торговли бессрочными USDT-контрактами на Bybit.
Система считает сигнал и размер позиции. Long или Short выбирает владелец, а утилита отправляет ордер со стопом.
Purser значит «казначей». Проект входит в линейку Steward.

> Это не инвестиционная рекомендация. Доходность не обещана, а преимущество какой-либо стратегии не доказано.

## Принципы

- Сделки исполняет владелец. Код не отправляет ордера на боевой счёт.
- Лимиты риска живут только в `purser/limits.py`. Интерфейс, сигналы и LLM их не обходят.
- Стоп стоит на бирже с момента открытия позиции. Ордер без стопа не отправляется.
- Секреты лежат в `.env` и не попадают в репозиторий.
- Деньги и количества считаются в `Decimal`, размер округляется вниз.

## Лимиты (утверждены 2026-11-15)

| Параметр | Значение |
|---|---|
| Риск на сделку | 7,5% депозита |
| Плечо | старт 1x, потолок 1,25x |
| Дневной лимит | 2 стопа |
| Недельный лимит | 3 стопа |
| Порог остановки | минус 40% от пика |
| Жёсткий потолок | минус 70% |

## Состояние

| Шаг | Что | Статус |
|---|---|---|
| 0 | Лимиты и осуществимость | готово |
| 1 | Данные, пул монет, сводка | следующий |
| 2 | Тонкое исполнение на демо | план |
| 3 | Бэктест | план |
| 4 | Сигналы | план |
| 5 | Демо 4 недели, затем live | план |

## Запуск

Нужен Python 3.12. Внешних зависимостей на шаге 0 нет.

```bash
python -m unittest discover tests
python -m purser feasibility --equity 40.63
```

## Структура

- `purser/limits.py`: лимиты риска.
- `purser/sizing.py`: размер позиции, чистые функции на `Decimal`.
- `purser/bybit_public.py`: публичные данные Bybit без ключей.
- `purser/feasibility.py`: отчёт шага 0.
- `tests/`: тесты.
