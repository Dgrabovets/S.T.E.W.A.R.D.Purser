# S.T.E.W.A.R.D.Purser

Ядро на Python для торговли бессрочными USDT-контрактами на Bybit.
Система считает сигнал и размер позиции. Long или Short выбирает владелец, а утилита отправляет ордер со стопом.
Purser значит «казначей». Проект входит в линейку Steward.

> Это не инвестиционная рекомендация. Доходность не обещана, а преимущество какой-либо стратегии не доказано.

## Принципы

- Сделки исполняет владелец. Код не отправляет ордера на боевой счёт.
- Лимиты риска живут только в `purser/limits.py`. Интерфейс, сигналы и LLM их не обходят.
- Стоп стоит на бирже с момента открытия позиции. Ордер без стопа не отправляется.
- Секреты лежат в `.env` и не попадают в репозиторий.
- Деньги и количества считаются в `Decimal`, размер округляется вниз.

## Лимиты (утверждены 2026-11-15)

| Параметр | Значение |
|---|---|
| Риск на сделку | 7,5% депозита |
| Плечо | старт 1x, потолок 1,25x |
| Дневной лимит | 2 стопа |
| Недельный лимит | 3 стопа |
| Порог остановки | минус 40% от пика |
| Жёсткий потолок | минус 70% |

## Состояние

| Шаг | Что | Статус |
|---|---|---|
| 0 | Лимиты и осуществимость | готово |
| 1 | Данные, пул монет, сводка | готово |
| 2 | Тонкое исполнение на демо | следующий |
| 3 | Бэктест | план |
| 4 | Сигналы | план |
| 5 | Демо 4 недели, затем live | план |

## Настройки

Адрес API, паузы и повторы запросов, папка истории, размеры свечей и пороги отбора пула читаются из окружения и файла `.env`. Файл `.env` создаёт владелец, в git он не попадает. Лимиты риска в `.env` не выносятся, они только в `purser/limits.py`.

| Переменная | По умолчанию | Что задаёт |
|---|---|---|
| `PURSER_BASE_URL` | `https://api.bybit.com` | Адрес API Bybit |
| `PURSER_ATTEMPTS` | `3` | Попыток запроса при временной ошибке |
| `PURSER_RETRY_PAUSE_SECONDS` | `2` | Пауза между попытками, секунды |
| `PURSER_TIMEOUT_SECONDS` | `20` | Ожидание ответа биржи, секунды |
| `PURSER_DATA_DIR` | `data` | Папка с историей |
| `PURSER_INTERVALS` | `60,240` | Размеры свечей в минутах через запятую |
| `PURSER_POOL_SIZE` | `10` | Монет в пуле |
| `PURSER_MIN_HISTORY_DAYS` | `730` | Моложе стольких суток монета в пул не идёт |
| `PURSER_HISTORY_DAYS` | `730` | За сколько суток качаем историю |
| `PURSER_MAX_SPREAD` | `0.0005` | Наибольший спред, доля от цены |
| `PURSER_MAX_STEP_USDT` | `1` | Наибольший шаг лота для пометки «можно торговать», USDT |

## Запуск

Нужен Python 3.12. Внешних зависимостей пока нет.

```bash
python -m unittest discover tests
python -m purser feasibility --equity 40.63
python -m purser pool
python -m purser fetch
```

`pool` печатает сводку по 10 монетам. `fetch` докачивает свечи (1 и 4 часа) и финансирование за два года в `data/`, папка в репозиторий не попадает.

## Структура

- `purser/limits.py`: лимиты риска.
- `purser/sizing.py`: размер позиции, чистые функции на `Decimal`.
- `purser/bybit_public.py`: публичные данные Bybit без ключей.
- `purser/feasibility.py`: отчёт шага 0.
- `purser/pool.py`: отбор пула и сводка.
- `purser/store.py`: история в CSV с докачкой.
- `purser/settings.py`: настройки из окружения и `.env`.
- `tests/`: тесты.
